Versão 1.4. - É possível procurar diretamente controles já criados no ir.molsmart.com.br

Precisa colocar os dados do GW8, SALVAR 1 vez, fazer refresh e a lista vai aparecer. 
Se vc tiver um usuário no ir.molsmart.com.br, pode colocar o email no campo de usuário, e os seus controles privados vão aparecer na lista também.
